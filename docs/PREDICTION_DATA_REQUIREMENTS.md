# NAGARLENS — Predictive Data Requirements Specification

> **Document Version:** 1.0.0  
> **Status:** Production Specification  

---

## 1. Minimum Dataset Thresholds

- **Baseline Prediction**: Requires minimum 1 field observation with valid WGS84 coordinates and defect category.
- **Deterioration Trend**: Requires minimum 2 observations captured at least 7 days apart.
- **Statistical Anomaly Detection**: Requires minimum 3 historical observations on the same asset node.
